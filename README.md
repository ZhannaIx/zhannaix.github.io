# zhannaix.github.io — сайт Жанны Иксановой

## Что внутри
- `index.html` — главная: первый экран, «Обо мне», контакты
- `cases.html` — «Кейсы»: как я работаю и три раздела
- `realized.html` — «Реализация» (7 проектов)
- `concepts.html` — «Концепции» (3 проекта)
- `ecosystems.html` — «Экосистемы» (6 проектов)
- `css/site.css` — все стили сайта
- `images/` — фото проектов, монограмма (иконки) и картинка для превью ссылки

Скрипты встроены в каждую страницу, отдельной папки `js/` больше нет.

## Как опубликовать
1. Откройте репозиторий `zhannaix.github.io` на GitHub.
2. Удалите старые файлы: `index.html`, `selected-cases.html` (если есть), папки `css/`, `js/` и старые картинки в `images/`.
3. Нажмите **Add file → Upload files** и перетащите всё содержимое этой папки (не саму папку, а файлы и папки внутри неё).
4. Нажмите **Commit changes**.
5. Через 1–2 минуты сайт обновится по адресу https://zhannaix.github.io. Если нет — **Settings → Pages → Deploy from a branch → main / (root)**.

## Полезные ссылки для откликов
- https://zhannaix.github.io/realized.html — реализованные проекты
- https://zhannaix.github.io/concepts.html — концепции
- https://zhannaix.github.io/ecosystems.html — центры, команды, программы
- Ссылка на конкретный кейс открывает его сразу: например, `realized.html#royal-castle`, `realized.html#living-paintings`

## Форма обратной связи
Сообщения уходят в ту же Google-таблицу, что и раньше (тот же адрес Google Apps Script).
После публикации отправьте себе тестовое сообщение и проверьте, что оно появилось в таблице.
